## 2024-09-24 - Accessibility for Text-Based Symbols Inside Buttons
**Learning:** Screen readers might read text-based symbols like `[X]`, `[ESC]`, or `✕` in unintended ways or fail to give correct context when they are used as icons inside close buttons. Additionally, plain buttons often lack clear visual focus indicators which breaks keyboard navigation.
**Action:** Always wrap text-based symbols inside buttons in a `<span aria-hidden="true">` to prevent confusing screen reader announcements without hiding the button itself. Add an explicit `aria-label` to the parent `<button>` (e.g. "Close") for screen readers. Ensure you add `focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-cyan-500 rounded` (or similar utilities) to support visual keyboard navigation.
