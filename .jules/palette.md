## 2023-10-25 - Managing Text-Based UI Symbols and Focus Styles
**Learning:** This application makes heavy use of text-based symbols (like `[ESC]`, `[X]`, `>>`) for its brutalist/terminal aesthetic. When these are inside interactive elements like buttons, screen readers announce them literally, leading to confusing UX (e.g. "Left bracket E S C right bracket button"). Also, buttons need explicit `focus-visible` styles against dark backgrounds since default outlines are often invisible.
**Action:** When working with text-based UI symbols in this app, wrap the symbol in a `<span aria-hidden="true">` to prevent confusing announcements and provide a clear `aria-label` on the parent button. Ensure interactive elements use Tailwind's explicit `focus-visible:ring-2` to provide clear keyboard focus indicators. Furthermore, when grouping radio-like buttons, use a `<div role="group" aria-labelledby="...">` instead of improperly wrapping the group in a `<label>`.
