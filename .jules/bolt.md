## 2024-05-24 - React List Rendering with Stable Callbacks and Memoization
**Learning:** In a live chat/feed component (`VentSessionLog`), unconditionally recreating item components or passing unstable callbacks causes the entire list to re-render every time a new item is appended. When a list grows long, this can cause significant performance stutter and block the main thread. We found that extracting the mapped item to a `React.memo` component wasn't enough because the `handlePlayAudio` callback depended on state variables that changed on every playback toggle.
**Action:** Always wrap large list child components in `React.memo()` and pair them with `useCallback` for event handlers. To prevent the callback from going stale while keeping its reference stable, use the "latest-ref pattern" by saving volatile state (like `playingAudioId`) to a `useRef` and reading from `.current` inside the callback.
