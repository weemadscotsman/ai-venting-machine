## 2024-05-19 - React.memo with latest-ref pattern for list item callbacks
**Learning:** When memoizing a list item component (`React.memo`) that accepts a callback (e.g., `handlePlayAudio`), standard `useCallback` implementations might cause the callback reference to change whenever internal state changes (like the `playingAudioId` or `apiKey`). If you omit those dependencies to keep the reference stable, you create a stale closure.
**Action:** Use the "latest-ref" pattern alongside `useCallback`. Store the rapidly changing state variables in a `useRef` updated via `useEffect`. Then, the `useCallback` dependency array can be empty (or rely only on refs), ensuring a truly stable function reference that allows `React.memo` to effectively prevent list items from re-rendering, while still accessing the correct, latest state inside the callback.
