## 2026-09-18 - Memoizing List Items to Prevent O(n^2) Re-renders
**Learning:** In dynamically growing lists (like chat logs), unconditionally mapping over array items causing React to re-render all previously rendered list items creates an O(n^2) performance bottleneck, especially when audio playback components interact with refs and callbacks. Combining `React.memo()` with a `useCallback()` wrapper and the `latest-ref` pattern to stabilize callback functions ensures that only newly added list items or actively playing items are rendered.
**Action:** When extracting components inside large, dynamically growing lists in React, wrap the individual list item in `React.memo` and ensure that all callbacks passed to it are stabilized using the latest-ref pattern (combining `useRef` and `useCallback`) to preserve reference equality across renders without relying on stale closures.
