## 2024-06-25 - React Memoization and Latest-Ref Pattern for O(N²) Render Bottlenecks
**Learning:** In React components that append items iteratively on an interval (like a chat with a "typing" effect), mapping inline components causes an O(N²) render complexity. Every new appended item forces all previous items to re-render. Additionally, extracting the item to a child component requires stabilizing any passed callbacks (like `onPlay`), which is difficult when the callback depends on frequently changing state (like `playingAudioId`) or non-reactive references (like `apiKey`), leading to stale closures or constant reference recreation.
**Action:** Extract list items into a child component wrapped in `React.memo()`. Pass stable callbacks to these items by using `React.useCallback()`. To avoid stale closures without breaking the callback reference on every state change, implement the "latest-ref" pattern by storing changing variables in a `useRef` updated during `useEffect` (or `useLayoutEffect`), and read from the ref inside the callback.
