## 2024-05-24 - Memoizing List Items with Stable Callbacks
**Learning:** Extracting complex elements rendered inside a `.map()` loop (like `VentSessionLog`'s message blocks) into a dedicated component wrapped with `React.memo` significantly reduces unnecessary re-renders. When the item component expects callback props (like `onPlayAudio`), the callbacks must be completely stable, which can be achieved via `useCallback` coupled with a latest-ref pattern (`useRef`) to avoid stale closures while maintaining referential equality.
**Action:** When rendering long or continuously updating lists where each item is expensive or maintains its own complex structure, extract the item into a `React.memo` component and explicitly verify that any function props passed down maintain stable references.
