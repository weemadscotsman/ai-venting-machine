## 2025-03-09 - Stabilizing Callbacks with Latest-Ref Pattern in React.memo
**Learning:** When using `React.memo` to optimize rendering for list items, passing an inline or dynamically bound function prop (like `onPlayAudio`) can cause the component to unnecessarily re-render because the function's identity changes on every render. However, stabilizing the callback using `useCallback` directly can lead to stale closures if the callback depends on state that changes frequently (like `visibleMessages`).
**Action:** Implemented the "latest-ref pattern" by saving the latest version of the unstable function (e.g., `handlePlayAudio`) into a ref via `useLayoutEffect`, and then passing a stable wrapper (using `useCallback` with an empty dependency array) that calls the ref. This approach ensures the child component remains fully memoized while still maintaining access to the latest component state inside the callback without triggering re-renders.
